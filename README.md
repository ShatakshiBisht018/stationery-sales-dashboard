# 📊 Stationery Sales & Revenue Analysis Dashboard

An interactive, data-driven Excel analytics dashboard designed to monitor and evaluate sales performance, revenue drivers, and distribution metrics across major Indian stationery brands, retail partners, and regional markets.

---

## 📈 Key Metrics & Executive Summary

- **Total Revenue:** ₹1,451,643.80
- **Total Units Sold:** 10,334 units
- **Average Order Value (AOV):** ₹14,516.44
- **Top Brand:** Faber-Castell (₹571,697.20)
- **Top Product Category:** Art & Craft (₹672,087.40)
- **Leading Region:** East (₹403,836.00)

---

## 🚀 Key Features & Functionality

- **Interactive KPI Cards:** Dynamic summary metrics showing total sales volume, order averages, and top-performing brands.
- **Regional Slicers:** Flexible filtering allowing instant dynamic drill-downs across East, West, North, South, and Central zones.
- **Granular Order Log:** 100 structured order records capturing Sale ID, Date, Brand, Product, Retailer, Discounts, and Net Revenue.
- **Backend Summarization:** Automated aggregation sheets powering time-series revenue trends, brand market share, and product category breakdowns.

---

## 🗂️ Workbook Architecture

| Sheet Name | Description | Key Focus |
| :--- | :--- | :--- |
| **`Dashboard`** | High-level interactive control center | KPI summaries, region slicers, visual trend cards |
| **`Sales Data`** | Raw transaction log (100 records) | Units sold, unit prices, discounts, net revenue formulas |
| **`Summary`** | Dynamic pivot/aggregation layer | Monthly trends, brand revenue splits, category/region metrics |

## 📥 How to Run / Explore

1. Download or clone this repository to your local computer.
2. Open `Stationery_Sales_Revenue_Dashboard.xlsx` using **Microsoft Excel** (2016 or newer recommended for optimal slicer interactivity).
3. Select the **`Dashboard`** tab to interact with regional slicers and observe real-time KPI recalculations.
